# Data Analytics & Machine Learning in Finance

**Can machine learning and financial news help anticipate credit risk?**

Two academic projects exploring firm-level credit-rating downgrades and news-implied sovereign default risk, combining practical predictive modelling with collaborative financial research communication.

| Project | Format | Focus |
| --- | --- | --- |
| [01 — Credit Rating Downgrades](01-credit-rating-downgrades/) | Applied Python analysis | Logistic regression, random forest, gradient boosting, time-based testing |
| [02 — News-Implied Sovereign Risk](02-news-implied-sovereign-risk/) | Collaborative research-paper review | NLP methodology, sovereign CDS, rating downgrades, equity spillovers |

## Project scope
The first project is a cleaned, reproducible adaptation of an individual course assignment. The second summarizes and discusses a published academic paper presented as a separate group assignment. It does **not** claim to reproduce the authors’ NLP pipeline or results independently. The two projects have distinct authorship and attribution contexts.

## Reproducibility and responsible publication
The course credit-rating dataset is not redistributed. Authorized users can provide it locally; see the project data README. The original assignment handout, student-ID submission notebook, and group slide deck are excluded. The group presentation is withheld pending collaborator consent. No external datasets or independently unverified model results are claimed.
